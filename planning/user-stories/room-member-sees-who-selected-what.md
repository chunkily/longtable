As a Room Member
I want to see which token each person at the table has selected
So that "this one" means the same thing to everyone when we're talking about the map

## Acceptance criteria

- [ ] When someone selects a token, everyone else sees it marked in that person's colour
- [ ] My own selection still looks different from everyone else's
- [ ] When several people select the same token, I can tell that each of them has
- [ ] I can find out who has selected a token without guessing from colours alone
- [ ] Arriving, refreshing or reconnecting shows me the selections that are already there
- [ ] A Player never learns about a hidden token from someone selecting it
- [ ] A dropped connection that comes back within the grace period doesn't clear anything

## Notes

From the first playtests (October 2026). The GM's selections are shown like everyone else's, by
decision — see [shared-token-selection](../backlog/shared-token-selection.md).
