As a GM
I want to flag a set of tokens as "the party" and add them to any scene in one action
So that I don't have to re-create the same handful of tokens by hand every time I build a new scene

## Acceptance criteria

- [ ] A GM can flag or unflag any token as part of the party.
- [ ] An "Add party" action on a scene creates a fresh token for each flagged token, copying its
      name, art, size and owner.
- [ ] Added tokens spread over free squares rather than stacking, the same as a batch created from
      the New token dialog.
- [ ] Only a GM can flag tokens or trigger "Add party".
