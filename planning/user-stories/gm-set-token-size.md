As a GM
I want to choose a token's size when I create it
So that a Large or Huge creature visibly takes up the right amount of the grid, not just one square

## Acceptance criteria

- [ ] Token creation lets me pick a size: Tiny, Small, or Medium (all 1×1 squares), Large (2×2), Huge (3×3), or Gargantuan (4×4)
- [ ] The chosen size is what's rendered on the map — a Large token visibly covers a 2×2 area, not just its origin square
- [ ] Leaving the size unset creates a Medium (1×1) token, matching today's default
