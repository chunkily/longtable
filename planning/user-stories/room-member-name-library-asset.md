As a Room Member

So that I can find it by what it is rather than by whatever the file happened to be called

## Acceptance criteria

- [ ] A name field is offered when adding an asset, pre-filled with the filename minus its
      extension
- [ ] The name is what the library and the pickers show
- [ ] Search matches the name as well as the attribution text
- [ ] An asset already in the library can be renamed, and re-credited, without re-uploading it
- [ ] A name is per-room: two rooms holding the same image can name it differently
