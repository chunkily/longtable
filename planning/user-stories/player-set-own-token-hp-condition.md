As a Player
I want to set the numeric trackers (e.g. HP, AC, a resource) and conditions on the token I own
So that I can track my own character's damage and status without asking the GM to do it for me

## Acceptance criteria

- [ ] I can edit tracker values and conditions on a token only if I own it
- [ ] Attempting to edit a token I don't own is rejected with no effect
- [ ] Changes are visible to all Room Members in real time
- [ ] Tracker values and conditions are visible on hovering over the token, and in its detail panel
