As a Room Member
I want to browse the asset library scoped to my room
So that I can see what art is already available in this room without needing a direct link to each file

## Acceptance criteria

- [ ] The library only shows assets belonging to this room, not other rooms
- [ ] Viewing a private room's library requires being a member of that room
- [ ] Each asset shows its attribution/license info if the uploader provided any
- [ ] Assets are previewable directly on the page
