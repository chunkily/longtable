As a GM
I want to switch which scene is currently active from a list of scenes in the room
So that I can move the party between different maps (e.g. tavern to dungeon) without recreating a scene every time

## Acceptance criteria

- [ ] I can see a list of all scenes that exist in the room
- [ ] I can select any existing scene from the list to make it the active scene
- [ ] Room Members' view updates to the newly active scene in real time
- [ ] Creating a new scene no longer needs to auto-activate it as the only way to reach it (current behavior, worked around the lack of this list)
