As a GM
I want to set up to three numeric trackers (e.g. HP, AC, a resource) and conditions on any token
So that I can track damage and status effects for every creature on the map, including NPCs and player characters

## Acceptance criteria

- [ ] Each token has three independent numeric tracker slots I can set a value on (a single current number per slot, no max for now — similar to Roll20's token bars)
- [ ] I can label each tracker (e.g. "HP", "AC") so it's clear what it represents
- [ ] I can add and remove conditions/status tags on a token
- [ ] This works on any token in the room, regardless of who owns it
- [ ] Changes are visible to all Room Members in real time
- [ ] Tracker values and conditions are visible on hovering over the token, and in its detail panel
