As a Room Member
I want the dice in a roll listed from highest to lowest
So that I can count how many beat a target without reading every die

## Acceptance criteria

- [ ] Every die in a roll is listed highest first
- [ ] Different kinds of dice in one roll are sorted separately, not mixed together
- [ ] Everyone sees the same order, including after a refresh
