As a GM
I want to delete a token I no longer need, and recover it if I delete the wrong one
So that I can clean up the map without losing anything if I misclick

## Acceptance criteria

- [ ] A Delete button in the token details section above chat removes the currently selected
      token, for everyone in the room
- [ ] Only a GM can delete a token, matching who's allowed to create one
- [ ] I can undo the deletion to bring the token back in the same place with the same properties
- [ ] Deleting the selected token clears the current selection, the same as if I'd clicked empty
      map space
