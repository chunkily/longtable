As a Room Member
I want to switch tools with a key, and to be able to find out which key
So that I can keep my eyes on the map instead of hunting along the toolbar

## Acceptance criteria

- [ ] Every tool on the toolbar can be reached with a single key
- [ ] Pointing at a tool tells me its key
- [ ] I can open a list of every shortcut from inside the room
- [ ] Typing in chat or a dialog never switches tools
- [ ] Shortcuts never take over the browser's own (Ctrl+F, Ctrl+R and so on)
- [ ] A key that would do nothing for me — a Player pressing fog's — does nothing
