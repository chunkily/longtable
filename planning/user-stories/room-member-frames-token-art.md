As a Room Member
I want to choose how a picture is cropped into a token when I upload it
So that a portrait I bring looks like the character on the map, not squashed into a circle

## Acceptance criteria

- [ ] Token art is never stretched or squashed on the map, whatever its shape
- [ ] Uploading non-square token art shows me how it will be cropped before it's added, already
      framed sensibly, so I can accept it as it is
- [ ] I can move the crop and zoom in on part of the picture
- [ ] What I see while cropping is the circle the token will actually show
- [ ] The map, the initiative tracker, the library and the pickers all show the same framing
- [ ] Square art goes straight in without asking

## Notes

From the first playtests (October 2026). Re-cropping art already in a library is deliberately not
part of this — upload the original again — and
[frame-token-art-at-upload](../backlog/frame-token-art-at-upload.md) says why.
