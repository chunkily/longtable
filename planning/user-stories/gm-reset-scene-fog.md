As a GM
I want to reset all fog on a scene back to fully hidden
So that I can start fresh (e.g. a new session, or after a big mistake) without manually re-hiding cells one by one

## Acceptance criteria

- [ ] A single action re-hides every previously revealed cell on the current scene
- [ ] This doesn't affect the map image or tokens, only fog state
- [ ] The reset is reflected for all Room Members in real time
